# 化学変化あて（kagaku-henka）

化学変化の例（炭酸水素ナトリウムを加熱・水に電流を流す・鉄と硫黄を加熱・酸化銅と炭素を加熱など）を見て、熱分解・電気分解・酸化・還元・酸素以外との化合のどれかを当てる1日5問の学習ゲーム。正解したら「分かれる？結びつく？」も選ぶ。中学2年理科「化学変化と原子・分子」。
